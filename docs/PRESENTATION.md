# English presentation and verification

The English portfolio edition translates the viewer, project status, eleven
principal Markdown reports, and six HTML inspection pages. Report generators
also emit English prose and plot labels, so regenerating a report keeps the same
language. Earlier research reports retain their original Russian prose.

## What changed

- Viewer controls, loading/error messages, date labels, structure names, help,
  accessibility labels, and links now use English.
- The main reports cover baseline registration, BIM inspection, shared cells,
  fixed-structure controls, cross-date LAS elevation, three semantic experiments,
  persistent surfaces, optional accuracy refinement, and camera localization.
- The repository includes the six principal HTML pages and all figures referenced
  by those pages and the eleven main reports. These are publication images;
  full Gaussian scenes, LAS, IFC, model weights, and intermediate arrays remain
  excluded. The reports can be read without restoring the 3D dataset.
- English viewer screenshots replace the portfolio preview and the two
  fixed-structure inspection screenshots.

## Numerical evidence is unchanged

This is a presentation update, not another registration experiment. CSV results,
transformation matrices, masks, protocol parameters, and original validation
receipts are unchanged from the pre-translation snapshot:
[`7bed2a7`](https://github.com/AsylkhanKali/Splat2BIM/tree/7bed2a70dff8cb857de15a8ced653b8f59b3e6ff).

The edited report generators differ only in string constants. The additional
change in `check_static_structures.py` maps two frozen region IDs to English plot
titles; its numerical functions and evaluation statements are unchanged. Region
metadata retains its original labels so existing mask hashes stay intact. The
viewer applies English display names without modifying those input files.

Three report summaries update only their `source_sha256` metadata to identify
the current report generator: `stable_structures`,
`reviewed_structural_refinement`, and `semantic_3dgs_registration`. Their numerical
fields remain identical. The original `validation.json` and `delivery_checks.json`
files describe the earlier research runs. A historical receipt may therefore
refer to a pre-translation report or source hash. It is not a receipt for this
English publication, and it was not rewritten to make the new presentation
appear historically verified.

Current checks are recorded separately in
[`results/english_publication.json`](../results/english_publication.json):
numerical-file comparisons, report-table comparisons, Python/JavaScript checks,
the 79-test numerical suite, local report assets, and viewer smoke checks across
all seven dates. The scientific fitting pipelines were not rerun for translation.

## Regenerating the presentation

The committed reports and figures are ready to read. With complete local
experiment outputs and original camera images restored, the principal report
generators can be rerun from the repository root:

```sh
python scripts/report_bim.py
python scripts/report_static_structures.py
python scripts/report_las_vertical.py
python scripts/report_semantic_fusion.py
python scripts/report_semantic_3dgs.py
python scripts/report_semantic_3dgs_registration.py
python scripts/report_stable_structures.py
python scripts/report_structural_refinement.py
python scripts/report_camera_localization.py
```

The baseline multi-date and shared-cell reports are emitted by
`compare_dates.py` and `check_common_areas.py`, respectively. Those scripts also
perform numerical work. `check_static_structures.py` produces the region-selection
plots as part of its evaluation. During translation, those plots were redrawn
from the unchanged saved measurements and original LAS context without rerunning
the fit or replacing validation receipts. Viewer screenshots are captured from
the running application, not generated by report scripts.

Serve the project with `python scripts/serve_viewer.py` to use HTML inspection
pages locally. Opening the six report pages needs only their published assets;
opening the 3D viewer additionally requires the large scene files and npm
dependencies described in [DATA.md](DATA.md).
